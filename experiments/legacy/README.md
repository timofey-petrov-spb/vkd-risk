# Архив: временные слои Б до поставки A2/A4

Эти два модуля **не участвуют в расчёте** с версии алгоритма 0.6.0 (19.09.2026).
Они сохранены как исторические образцы: на них считались эксперименты
`docs/EKSPERIMENTY.md` и первые редакции `docs/EKSPERIMENTY_PROGNOZ.md`,
и по ним читаются прежние записи журнала.

| файл | чем был | чем заменён |
|---|---|---|
| `stub_history.py` | события DONKI из карточек `data/archive_2024`, время публикации по реестру A1, прогноз прихода выброса из полей прогона `enlilList` | `vkd.history` (A2): разбор ИСХОДНЫХ тел уведомлений, архив наблюдений GOES 2024, окончательный ряд Kp GFZ |
| `stub_sources.py` | живой запрос → кеш → снимок репозитория для GOES, Kp, TLE | `vkd.sources` (A4): те же три состояния источника, плюс `noaa_latest` и квитанции байтов |

Почему папка названа `legacy`, а не оставлена на прежнем месте: в путях рабочего
конвейера не должно быть слова «stub» — ни на экране, ни в выгрузке, ни в импорте
(бриф экрана, п. 6). Слово «архив» в этом README и имя папки говорят прямо, что
это не действующий слой.

Что изменилось по существу при переходе (а не только по имени):

- прогноз прихода выброса берётся из **опубликованного уведомления** DONKI
  (`facts.kp_range_min/max`), а не из полей прогона `kp_90`/`kp_180` поздней
  карточки: время размещения конкретной версии карточки не доказано (R10);
- уровень протонного события — **нижняя граница** порогового сообщения,
  а не «измеренный поток»;
- появился численный ряд наблюдений GOES за 2024 год — в разборе он работает
  как наблюдение, в строгом прогнозе исключён с названной причиной.

Запускать эти модули не нужно. Если понадобится воспроизвести старые числа,
импорт — `experiments.legacy.stub_history` / `experiments.legacy.stub_sources`.
