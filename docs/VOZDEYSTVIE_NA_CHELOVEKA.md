# Как эти воздействия действуют на человека

Количественная часть. Каждое число с источником.

---

## 1. Цепочка величин

Путать эти величины — самая частая ошибка, и на защите её поймают первой.

```
поглощённая доза D, Гр      сколько энергии осталось в веществе
        ↓  × w_R  (или × Q(L))
эквивалентная доза H, Зв    поправка на вид излучения
        ↓  × w_T, сумма по органам
эффективная доза E, Зв      поправка на радиочувствительность органов
```

Нормативные таблицы ОСТ 134-1044-2007 дают **поглощённую дозу в кремнии**.
Пределы задаются в **эквивалентной** или **эффективной**. Переход обязателен,
и его надо показать явно.

---

## 2. Взвешивающие коэффициенты излучения w_R

ICRP-60, через ECSS-E-ST-10-12C таблица 11-1.

| излучение | w_R |
|---|---|
| фотоны, все энергии | 1 |
| электроны и мюоны, все энергии | 1 |
| нейтроны < 10 кэВ | 5 |
| нейтроны 10…100 кэВ | 10 |
| нейтроны 100 кэВ…2 МэВ | **20** |
| нейтроны 2…20 МэВ | 10 |
| нейтроны > 20 МэВ | 5 |
| **протоны (не отдачи), > 2 МэВ** | **5** |
| альфа, осколки деления, тяжёлые ядра | **20** |

**Следствие для нашего расчёта.** Электроны идут с коэффициентом 1,
протоны с 5. То есть протонный вклад в зивертах в пять раз больше, чем
в греях. Пересчёт дозы за шестичасовой выход на рукавах:

| составляющая | мГр | w_R | мЗв |
|---|---|---|---|
| электроны | 8,778 | 1 | 8,78 |
| протоны поясов | 0,710 | 5 | 3,55 |
| протоны СКЛ | 0,092 | 5 | 0,46 |
| **сумма** | 9,58 | | **12,8** |

Доля протонов вырастает с 8 % до 31 %. Это надо посчитать правильно
с самого начала.

## 3. Взвешивающие коэффициенты тканей w_T

ICRP-60 таблица A-3, через ECSS-E-ST-10-12C таблица 11-2.

| орган или ткань | w_T |
|---|---|
| гонады | 0,20 |
| красный костный мозг | 0,12 |
| толстая кишка | 0,12 |
| лёгкие | 0,12 |
| желудок | 0,12 |
| мочевой пузырь | 0,05 |
| молочная железа | 0,05 |
| печень | 0,05 |
| пищевод | 0,05 |
| щитовидная железа | 0,05 |
| прочие ткани и органы | 0,05 |
| **кожа** | **0,01** |
| поверхность кости | 0,01 |

**У кожи коэффициент самый низкий, 0,01.** Это количественная причина, почему
сравнивать дозу на кожу с общим пределом нельзя: в эффективную дозу кожа
вносит один процент.

## 4. Функция качества Q(L)

ICRP-60, через ECSS-E-ST-10-12C, уравнение (3). Применяется, когда известен
спектр по линейной передаче энергии.

```
L < 10 кэВ/мкм        Q = 1
10 ≤ L ≤ 100          Q = 0,32·L − 2,2
L > 100               Q = 300/√L
```

`L` — неограниченная ЛПЭ в воде.

## 5. Что именно делает каждое воздействие

| воздействие | куда доходит | что поражает |
|---|---|---|
| электроны поясов | первые доли г/см², дальше нет | **кожа**, поверхностные ткани |
| тормозное от электронов | глубоко, но слабо | всё тело, малый вклад |
| протоны поясов | глубоко | **внутренние органы**, кроветворные |
| протоны вспышки | глубоко, много и быстро | **острое поражение**, кроветворные |
| тяжёлые ядра ГКЛ | насквозь | ЦНС, хрусталик, отдалённые эффекты |
| удар микрочастицы | пробой оболочки | **разгерметизация**, механическая травма |

**Ключевая асимметрия проекта.** Электроны дают около 90 % дозы в тонких
зонах, но всю её кладут в кожу, у которой w_T = 0,01. Протоны дают меньше
грей, но с коэффициентом 5 и в глубину, то есть в органы с w_T до 0,12.

Поэтому **доза на кожу и доза на органы — два разных числа с двумя разными
пределами**, и показывать их надо раздельно.

## 6. Пределы

### 6.1 ГОСТ 25645.215-85, формула проверена

```
G_н(T) = 0,05 + 4·(1 − exp(−T/72))      Зв, T в месяцах
контрольная часовая = G_н(T) / (720·T)
нормативный риск    = 0,6·10⁻⁴ на месяц полёта
```

Сверено с справочной таблицей стандарта по всем восьми строкам.

| | значение |
|---|---|
| за 6 месяцев | 370 мЗв, часовая 85 мкЗв/ч |
| за 12 месяцев | 664 мЗв, часовая 76 мкЗв/ч |
| за профессиональную деятельность | **4 Зв** |
| однократное воздействие | **0,5 Зв** |

Срок действия ГОСТа истёк 01.01.1992. Модель остаётся базой, пределы сверяем
с действующими.

### 6.2 Действующие, МУ 2.6.1.44-03-2004 (ООКОКП-2004)

| | значение | надёжность |
|---|---|---|
| за год орбитального полёта | **500 мЗв** | подтверждено несколькими источниками |
| за карьеру | **1 Зв** | согласуется: ровно вчетверо ниже 4 Зв ГОСТа |

**Современная норма строже старой.** За 12 месяцев ГОСТ давал 664 мЗв,
действующая норма 500 мЗв, то есть на 25 % жёстче. Для защиты это удобно:
модель берём из ГОСТа, сравниваем с действующим пределом, и оказываемся
в консервативную сторону.

### 6.3 Чего достоверно нет

**Пределы для кожи и для хрусталика.** В сети попадаются числа 50 мЗв на кожу
и 15 мЗв на хрусталик, но они похожи на пределы для наземного персонала,
а не для космонавтов, и первоисточник не подтверждён.

**В приложение эти числа не вносить.** Пока текст ООКОКП-2004 не найден:
дозу на кожу и на хрусталик показывать числом **без вердикта**, с подписью
«предел не установлен в доступных источниках».

Это честнее, чем поставить непроверенный порог, и на защите звучит сильнее.

## 7. Удар: что считаем и чего не заявляем

Критерий NASA для скафандра xEMU: при восьмичасовом выходе двух человек
на низкой орбите требование — **один отказ на 2500**. Скафандр ему
удовлетворяет.

Там же: **96 % ударного риска** приходится на мягкие зоны — руки, ноги,
перчатки.

Вероятность разгерметизации мы **не считаем**: валидированного уравнения
пробоя для многослойной ткани нет, NASA потребовалось более ста
высокоскоростных выстрелов, чтобы получить его для одного пакета.

Наш результат: карта экранирования и ожидаемое число попаданий частиц
заданного размера по зонам.
