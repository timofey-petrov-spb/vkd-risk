# A5 — спецификация метеороидов для реализации B2

Версия `grun-ecss-2020-v1`, 19.09.2026. Автор: А / Codex.
Владелец реализации `vkd/assess/` — Б; этот документ и контрольные данные
не являются второй реализацией оценщика. Договор не изменялся.

**Можно сразу подключать вычисление среднего фонового N.** Формула,
параметры, единицы, геометрия и контрольные числа ниже фиксированы.
Для заявления полного сезонного охвата короткой ВКД остаётся отдельная
проверка направленной составляющей (§5); наличие одного числа N её не заменяет.

## 1. Что рассчитываем

Природные метеороиды, масса **m ≥ 10⁻³ г**. Одна геометрия:
**односторонняя плоская пластина 1 м² со случайной ориентацией**.
Результат `N_expected` — безразмерное математическое ожидание числа
попаданий в эту опорную пластину за окно. Это не космонавт, не сферическая
поверхность, не пробой, не разгерметизация и не весь техногенный MMOD.

Основа: [ECSS-E-ST-10-04C Rev.1, 15.06.2020](../istochniki/ECSS-E-ST-10-04C-Rev1.pdf),
§10.2.2.2, формула 10-1; Annex C; J-5/J-6. SHA-256 исходного PDF есть
в `data/meteoroids/ecss_c2_streams.json`.

Применимость к МКС с наклонением 51,6°: средний Grün изотропен и не имеет
ограничения по наклонению 55°, присущего другой модели. Это позволяет
использовать его как средний фон; не означает учёта ориентации МКС или
направления метеорного потока. Для 2024 года используется опубликованная
до него климатологическая модель, не восстановленная популяция 2024 года.
Дата входит в сезонную часть; средний фон сам по себе не предсказывает
индивидуальные события. ГОСТ 167 не подмешивается к этой линии.

## 2. Формула и единицы среднего фона

В формулах масса `m_g` в **граммах**, положительная. Рабочий порог этой
версии фиксирован: `m_g = 0.001`. Изменение порога должно попасть в настройки
и манифест и пересчитать все слагаемые; нельзя менять только подпись.

```text
F1 = (2200 * m_g**0.306 + 15)**(-4.38)
F2 = 1.3e-9 * (m_g + 1e11*m_g**2 + 1e27*m_g**4)**(-0.36)
F3 = 1.3e-16 * (m_g + 1e6*m_g**2)**(-0.85)
F0_per_m2_year = 31557600 * (F1 + F2 + F3)
F0_per_m2_s = F1 + F2 + F3
```

`F0` — интегральный по массе поток частиц не меньше порога, при 1 а.е.,
до поправок Земли. Геометрия пластины уже содержится в определении.
**Дополнительных π, 4π или множителя 4 к F0 нет.** Плотность для указанного
массового порога не нужна. Если Б добавит отображение диаметра, стандарт
задаёт для Grün плотность 2,5 г/см³ и сферическую *частицу*; это не меняет
геометрию *мишени*. Порог 0,001 г соответствует примерно 0,914 мм.

По C-25:

```text
F_LEO_per_m2_year(h) = F0_per_m2_year * G_bar(h) * s_f(h) * K(h)
N_expected = area_m2 * integral(F_LEO_per_m2_year(t) dt_s) / 31557600
```

`31557600` — секунд в юлианском году, не число секунд в конкретном 2024 году.
`G_bar` — гравитационное усиление с распределением скоростей C-1;
`s_f` — экранирование Землёй; `K` — движение пластины по орбите.
Все три множителя безразмерны и применяются ровно один раз.

Для почти круговой орбиты МКС текущая инженерная реализация может
**явно** интерполировать каждый множитель линейно по высоте между узлами
J-6. Для 400–800 км узлы `(2.00, 0.63, 1.09)` и `(1.94, 0.70, 1.08)`.
Это приближение по справочной таблице, не точная новая формула ECSS.
Использовать фактические высоты A3; не фиксировать все точки на 400 км.
За крайними узлами нет экстраполяции или скрытого clamping. Таблица всех
конечных высот J-6 сохранена в `data/meteoroids/grun_reference.json`.

На временной сетке: трапеции с фактическими `dt_s`; обязательно добавить
точные начало и конец окна. Модуль A3 включает конечную точку горизонта.
Нельзя суммировать N по числу точек и получать лишнюю минуту на конце.
Если часть траектории отсутствует, вывести частичное покрытие и известный
интеграл только как частичный, не как полный N.

## 3. Численные эталоны для B2

Для m = 0,001 г, h = 400 км, A = 1 м², только средний фон:

| Величина | Значение |
|---|---:|
| F0, м⁻²·год⁻¹ | 5.967535505346167e-4 |
| F0 в таблице J-5 | 5.97e-4 |
| G_bar × s_f × K | 1.3734 |
| F_LEO, м⁻²·год⁻¹ | 8.195813263042426e-4 |
| N за 6 часов | 5.609728448352106e-7 |
| N за 8 часов | 7.479637931136140e-7 |

30 пар из J-5 с результатом формулы сохранены в JSON. На этих округлённых
табличных значениях максимальное относительное расхождение 0,488%;
сравнение с J-5 проводить с допуском 0,6%, а не требовать совпадения
последнего знака. Формулу против полного контрольного числа проверять
намного точнее, например `rtol=1e-10`. Это проверка арифметики, не оценка
физической точности модели.

Необходимые проверки Б: N линейно зависит от A и длительности при
постоянном потоке; дробление окна сохраняет сумму; поток убывает с ростом
порога массы; единицы времени не дают множителя 60/3600/31557600;
одинаковый фон двух равных окон даёт равнозначность по этому фактору.
Различие из-за высоты допустимо лишь после оценки чувствительности к
интерполяции J-6. Малое N не означает отсутствие других рисков.

## 4. Сезонная составляющая: что теперь установлено

ECSS §10.2.2.2c требует сезонные потоки для периодов менее трёх недель.
Таблица C-2 полностью перенесена в `data/meteoroids/ecss_c2_streams.json`:
**49 фактических строк** (41 + 8), хотя текст C.1.4 говорит о 50.
Недостающая строка не придумана. Имена сохранены как в данном PDF;
включая неоднозначное повторное название Aquarids — не исправлять его по памяти.

Разрешена неопределённость единиц по документации первичного инструмента:
[ESABASE2/Debris Release 13, rev.1.12, с.102](https://esabase2.net/wp-content/uploads/2024/05/ESABASE2-Debris-Technical-Description.pdf).
В McBride `m_kg = m_g / 1000`, `F_stream` — м⁻²·с⁻¹, поэтому
размерность табличного k — м⁻²·с⁻¹·кг^α. В Grün остаются **граммы**.
Прямая подстановка `0.001` вместо `0.000001` в поток ошибочна.

Для одного симметричного профиля C-3/C-5/C-6:

```text
delta_lambda_deg = signed shortest angular separation from lambda_max
Q = 10**(-B_per_deg * abs(delta_lambda_deg))
F_stream_raw_per_m2_s = k * m_kg**(-alpha) * Q
```

Солнечная долгота в градусах, периодическая по 360°. Отбор по 1% в C.1.4.3
относится к дальности `2/B`, а не к неизменному числу дней. При двух
профилях или асимметрии использовать C-4/C-8–C-11 с соответствующей
ветвью `before/after`, не удваивать обе экспоненты в точке максимума.
Числа для массы 10⁻⁶ кг и Q=1 в трёх потоках приведены в
`raw_stream_controls_not_plate_flux` JSON; это ещё не поток на нашу пластину.

Среднегодовой вклад потоков уже включён в Grün (примечание C-7).
Документация ESABASE2, с.100, подтверждает необходимость вычитания среднего:

```text
F_sporadic = F_Grun - mean_over_year(sum(F_stream_in_same_reference))
F_total(t) = F_sporadic + sum(F_stream_in_same_reference(t))
```

Среднее — интеграл по времени, делённый на длительность года; не простая
сумма табличных пиков. Все величины должны иметь одну геометрию, скорость,
положение и единицы до вычитания. Отрицательный F_sporadic означает ошибку
согласования моделей; заменять его нулём запрещено.

## 5. Граница готовности и честное подключение

Блокер основной формулы/параметров/единиц Grün закрыт: Б может реализовать
и показать **средний фон природных метеороидов на опорную пластину**.
Нельзя объявить полный краткосрочный метеороидный прогноз одним этим числом.

Перед полной сезонной реализацией остаётся подтвердить нормировку
направленного потока на площадь, преобразование к случайной односторонней
пластине, направление/скорость относительно станции, затенение Землёй и
согласованный годовой средний вклад. Скорость в C-2 уже содержит ускорение
к входу в атмосферу: нельзя снова бездумно применить к ней G_bar из J-6.
Математически среднее `max(0, cos θ)` по случайным нормалям равно 1/4,
но применять этот коэффициент к k можно только после подтверждения,
что исходный F действительно нормирован на плоскость, перпендикулярную лучу.

До этого по действующему плану: фактор среднего N вычислен; сезонное
покрытие механизма частичное. Приложение объясняет конкретный оставшийся
пробел вместо «модель вообще не подключена». Окончательный вердикт и
правила достаточности реализует Б; А не ослабляет их, чтобы получить
желательное слово на экране.

В манифесте сохранить: `model_id`, стандарт и SHA, `mass_g`, `area_m2`,
геометрию, секунды/год, способ поправок по высоте, применённые узлы J-6,
включён ли сезонный компонент, его версию/условия, исходные записи орбиты,
интервал интегрирования, шаг и полученную долю покрытия.

Критерии: Т2 — прослеживаемая физическая модель; Т3 — источник и численные
контроли; Т4 — доступная до 2024 модель и явная климатология; Т6 — неизвестное
не становится нулём; демонстрация — сравнение равных окон с объяснением,
что именно способно изменить N. Это спецификация A5, не готовая B2.
