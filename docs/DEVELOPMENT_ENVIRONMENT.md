## Сборка и запуск

Из корня репозитория:

```bash
source scripts/setup_env_macos.sh
bash scripts/build_check_macos.sh
./build-macos/bin/VKDRisk
```

Подключение среды действует только в текущем терминале и не заменяет системный Python. Qt установлен в `~/Qt/6.11.0/macos`; инструменты — в `~/.local/share/vkd-risk/`. Для Codex ручная активация пользователем не нужна: агент сам вызывает скрипт.

Локальные настройки `.vscode/settings.json` уже указывают на Qt, CMake и Ninja. Они исключены из Git, чтобы пути этого Mac не попали в настройки коллеги.

Нативная сборка использует `VKD_MONOLITH=OFF`. Она успешно собрана; существующее окно также прошло проверку запуска в offscreen-режиме. CTest сейчас находит **0 тестов** — расчётного кода и тестов ещё нет.

## Где остаётся Windows

В текущем `CMakeLists.txt` монолит привязан к MSVC и `/WHOLEARCHIVE`, а общие пресеты ограничены Windows. Поэтому Windows нужна для проверки именно этих режимов и выпуска Windows-приложения, но не для написания кода на Mac. Изменение общей сборки для полноценного монолита на Mac нужно согласовать с владельцем сборки.

На время подготовки использовалась уже существующая Windows 11 в Parallels. В ней установлены Qt 6.11.0 x64, MSVC Build Tools 18.10.1, Windows SDK 10.0.26100.0, CMake 3.30.5, Ninja 1.12.1, Inno Setup 7.1.0 и опциональный OpenCASCADE 7.9.2. Обе сборки и запуск обоих окон проверены. OCCT пока не подключён к приложению; его нативный macOS SDK не устанавливался, поскольку текущий код его не использует.

`C:\vkd-risk` — отдельная копия для проверки сборки, не второй рабочий Git-репозиторий. Основной исходный код и коммиты находятся на Mac. Перед повторной Windows-проверкой копию нужно синхронизировать; редактировать её независимо не следует.

Дополнительные файлы для коллеги или будущей контрольной сборки:

- `scripts/build_check_windows.cmd` — обнаруживает Visual Studio и собирает два пресета;
- `scripts/environment_report_windows.cmd` — выводит версии без изменения системной политики PowerShell;
- `environment/windows.json` — полученный снимок версий.

## Что сверить с коллегой

Qt **6.11.0** совпадает с версией, записанной в его скриптах. Фактические версии его MSVC, CMake, Ninja и SDK ещё нужно получить: совпадение всех инструментов двух машин пока не утверждается.

Для обмена исходниками разные ОС и компиляторы допустимы. Для Windows DLL отдельно сверяем x64, MSVC/toolset, Qt kit, Release/Debug и CRT. На Mac и Windows установлены разные версии CMake/Ninja; обе проверены на текущем проекте и записаны явно.
