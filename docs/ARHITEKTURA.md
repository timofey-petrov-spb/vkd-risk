# 1. Решение по архитектуре: модули без DLL

Замысел «сразу собрать всё модулями, чтобы остался каркас» — правильный.
Реализация через DLL — нет, и вот почему.

DLL означает C++, значит CMake, значит сборка. Трое суток, два человека, две
машины. Сборка станет отдельным проектом внутри проекта. В SafeSatelleS уже
был случай, когда прерванная линковка оставила плагин со старым ABI и модули
молча выпали из приложения. В три часа ночи второго дня это не диагностируется.

**Модульность, которая нужна, достигается в Python пакетами и реестром.**
Тот же разъём, то же «добавил модуль — он подхватился», ноль сборки:

```
core/registry.py       реестр воздействий
effects/radiation/     модуль, регистрируется при импорте
effects/impact/        модуль, регистрируется при импорте
effects/<новое>/       кладёте папку — оно появляется в приложении
```

Каркас для дальнейшего развития получается **лучше**, чем с DLL: пакет ставится
через pip, импортируется в блокнот, вызывается из веб-сервиса. DLL так не умеет.

Если после хакатона понадобится скорость, узкие места выносятся в C++ через
pybind11 **по одному**, не трогая остальное. Это правильный порядок: сначала
работает, потом быстро.

## 3.2 Первый счёт по этим таблицам

Проверка, что цепочка работает. Высота 400 км, выход 6 часов, полусфера.

| зона | электроны | протоны | СКЛ | сумма, мГр(Si) |
|---|---|---|---|---|
| шлем, фильтры подняты | 0,581 | 0,191 | 0,034 | **0,806** |
| шлем, фильтры опущены | 0,057 | 0,126 | 0,019 | **0,201** |
| торс | 0,763 | 0,208 | 0,038 | **1,009** |
| рукава и ноги | 8,778 | 0,710 | 0,092 | **9,580** |
| перчатки | 6,541 | 0,569 | 0,084 | **7,194** |

Три вывода, и все три — содержание защиты.

1. **Электроны дают 90 % дозы в тонких зонах.** Это физика пробега: электроны
   останавливаются в первых десятых долях г/см² и всю энергию отдают там.
2. **Рукава и ноги получают в 12 раз больше шлема.** Усреднение по скафандру
   уничтожило бы этот факт. Вот зачем нужна зонная модель.
3. **Опущенные светофильтры снижают дозу на шлеме вчетверо**, с 0,81 до 0,20.
   Готовая эксплуатационная рекомендация, полученная расчётом.

## 3.3 Оговорка, без которой числа выше опасны

Доза на тонких зонах — это **доза на кожу**, а не эффективная доза на организм.
Электроны таких энергий не доходят до внутренних органов, они тормозятся в
первых миллиметрах ткани.

Значит сравнивать 9,58 мГр с пределом 500 мЗв/год **нельзя**: у кожи отдельный,
существенно более высокий предел. Смешать их — грубая ошибка, и жюри из
медико-биологической области поймает её мгновенно.

Правильно так:
- тонкие зоны → **кожа**, сравнение с кожным пределом;
- торс и глубокие точки → **кроветворные органы**, сравнение с 500 мЗв/год;
- глаз → **хрусталик**, отдельный предел.

Плюс переход из рад(Si) в дозу в ткани. Метод приложения И ОСТ 1044 это
допускает дословно: расчёт ведётся для кремния, «хотя может быть определена
для любого материала».

**Задача на день 1: найти кожный предел и предел для хрусталика.** Пока их нет,
в приложении показывать дозу на кожу без вердикта, только числом.

# 6. Формулы, которые уже проверены

**Предел за полёт длительностью T месяцев, ГОСТ 25645.215-85:**

```
G_н(T) = 0,05 + 4·(1 − exp(−T/72))      зиверт
```

Сверено с справочной таблицей стандарта по всем 8 строкам, сходится
в пределах округления.

**Контрольная часовая доза:** `G_н(T) / (720·T)`. В стандарте дана картинкой,
выведена сверкой с таблицей; месяц принят за 720 часов. Для T = 6 мес это
85 мкЗв/ч.

**Нормативный риск:** `0,6·10⁻⁴ на месяц`, линейно.

**Прочие пределы:** за профессиональную деятельность 4 Зв, однократное
воздействие 0,5 Зв, действующий годовой 500 мЗв/год.

**Толщина вдоль луча:**

```
d(θ,φ) = Al-экв зоны / cos α  +  L_тело · ρ_ткани  +  ранец
```

**Перевод материала в алюминиевый эквивалент:** умножить на (Z/A)_мат / 0,4818.

# 11. Про заранее сделанные STEP-модели

Вы предложили подготовить STEP двух скафандров заранее. Здесь есть тонкость.

Оцифрованные таблицы из опубликованных стандартов — однозначно данные,
приносить их можно. CAD-модель скафандра — уже часть решения, и на вопрос
«это вы сделали до старта?» ответ будет неудобным.

**Безопасный и такой же быстрый путь:** подготовьте сегодня не файл, а
**спецификацию** — таблицу радиусов, длин, положений и границ зон,
параметризованную по росту и обхвату груди. По готовой спецификации CadQuery
строит оболочку за двадцать минут на самом хакатоне.

Экономия времени та же, вопросов нет.

Если в правилах вашего хакатона прямо разрешены заранее подготовленные
ассеты — тогда делайте STEP сегодня. Сверьтесь с текстом правил, решение
за вами.
