# Мастер-план проекта: состояние на 18.09.2026, вечер

Папка собирается многоагентной оркестрацией с фактической проверкой источников.
Первая фаза выполнена частично, дальше — пауза по лимиту сессии. Всё, что здесь
лежит, требует проверки применимости к текущему договору: это исследования,
не подтверждение готовности кода. Уточнения по архивам, единицам и ECSS —
в [PLAN_REVIEW.md](../PLAN_REVIEW.md); текущие задачи —
[PROGRESS.md](../PROGRESS.md).

## Что готово

Папка `research/` — шесть направлений из девяти, каждое как `<ключ>.md`
(читаемо) и `<ключ>.json` (структурно). Индекс: `research/README.md`.

| направление | ключ | для кого важно |
|---|---|---|
| Микрометеороиды и мусор как механизм | `mmod` | Codex: `vkd/conjunctions/`, статистика потока |
| Прочие факторы и условия работ | `otherfactors` | оба: что добавить третьей линией, что исключить |
| Критерии, доказательства, эксперименты | `criteria` | оба: что проверит жюри по каждому из 15 критериев |
| Нормативы и литература | `norms` | Claude: какие пункты цитируем, чего нет |
| Интерфейс, путь аналитика, развёртывание | `ux` | Claude: экраны, площадка для ссылки жюри |
| Архитектура, надёжность, воспроизводимость | `engineering` | Codex: слой источников, кеш, отключение, тесты |

Бонус из незавершённого направления «орбита»: `data/ost1044_cutoff/` —
таблица Ж.1 ОСТ 134-1044-2007, вертикальная жёсткость обрезания на 450 км,
эпоха 2010. Это вход для `cutoff_GV` в `TrajectoryPoint`.

## Чего нет

Три направления не успели завершиться: **космическая погода** (обязательный
механизм), **орбита и магнитные координаты** (Т2), **исторический режим** (Т4).
Их транскрипты сохранены и будут восстановлены при продолжении. До этого
по ним действуют: `CONTRACT.md` раздел 2, `data/spaceweather/README.md`,
`data/ost1044_belts/README.md`, `data/archive_2024/`, `experiments/demo_pipeline.py`.

Разделы мастер-плана `00_OBZOR` … `14_VOPROSY_DLYA_SVERKI` не написаны.
Их роль пока выполняют `docs/case/ANALIZ_KEYSA.md`, `CONTRACT.md`
и `PLAN_RAZRABOTKI.md` — они в силе.

## Как продолжить оркестрацию

Скрипт: `~/.claude/projects/C--Program-Files/<сессия>/workflows/scripts/vkd-master-plan-wf_424eb776-160.js`,
запуск `wf_424eb776-160`. Возобновление из кеша: шесть готовых направлений
и двенадцать голосов скептиков повторно не считаются. Перед возобновлением
скрипт надо облегчить: один скептик на утверждение вместо трёх, один проект
решения вместо трёх с судьями, критика разделов только там, где критик
нашёл ошибки. Перенос результатов в эту папку: `scripts/salvage_workflow.py`.
