## Готовый стык для экспорта и повтора Б

```python
meta, traj, proof = trajectory_with_provenance(
    t0, horizon_min, th.saa_B_threshold_nT, tle_path=tle_path,
    mode="history_review",  # историческая реконструкция, явно в снимке
)
hashes = {rid: record["sha256"] for rid, record in proof["records"].items()}
oem_id = next(rid for rid, record in proof["records"].items()
              if record["source_id"] == "nasa_jsc_oem")
# При повторе: те же исходные файлы, выбранный OEM и полный набор хешей.
meta, traj = trajectory(t0, horizon_min, th.saa_B_threshold_nT,
                       oem_raw_record_id=oem_id, expected_record_hashes=hashes)
```

Для live применяется сохранённый `tle_path`; в `proof.records` есть его
SHA и коэффициенты поля. Чужой набор входов/хешей даёт явную ошибку.
Старые примеры версии `0.3.0-b3` считались через другую орбиту: их нельзя
объявлять воспроизведёнными новым алгоритмом только по совпавшему вердикту.
После подключения экспорта Б повышает версию алгоритма и пересоздаёт примеры.
