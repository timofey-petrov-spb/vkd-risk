# ВКД-Риск

Оценка радиационного и ударного риска при выходе космонавта в открытый космос.

КосмоХакатон, кейс «Орбитальный риск», 18–20 сентября 2026.

## Что делает

По орбите, времени начала и продолжительности выхода считает по семи зонам
скафандра дозу и ожидаемое число попаданий микрочастиц, сравнивает дозу
с нормативными пределами и показывает, когда выход безопаснее.

Расчёт ведётся по действующим отечественным нормативам, а не по подобранным
формулам.

## Главный результат

Оба доминирующих воздействия сосредоточены в одних и тех же зонах —
руки, ноги, перчатки.

| | во сколько раз тонкие зоны хуже |
|---|---|
| доза | рукава получают в 12 раз больше шлема |
| удар | 96 % риска в мягких зонах (NASA, xEMU) |

Усреднение по скафандру этот факт уничтожает. Поэтому модель зонная.

## Два удалённых адреса

Работаем на GitHub, сдаём на GitVerse. Репозиторий один, адресов два.

| имя | адрес | роль |
|---|---|---|
| `origin` | GitHub | рабочий: ежедневные коммиты, журналы, обмен между нами |
| `gitverse` | `git@gitverse.ru:hackrus.experts/kosmo-piter_matmehovtsy_111.git` | сдача: там должно лежать готовое решение к дедлайну |

Обычная работа:

```
git push origin main
```

Отправка на сдачу (делать регулярно, не только в последний час):

```
git push gitverse main
```

Доступ к GitVerse выдают модераторы вручную после привязки username
в личном кабинете хакатона. Подключение по SSH, ключ добавляется
в профиле GitVerse: Настройки, вкладка «Ключи SSH/GPG».

## Сборка

```
scripts\setup_env.bat
cmake --preset mono   &&  cmake --build --preset mono
cmake --preset dll    &&  cmake --build --preset dll
```

Обе конфигурации обязаны собираться всегда.

Требуется: Visual Studio 2022 или 18, Qt 6.5+, CMake 3.25+ (формат пресетов v6), Ninja.
OpenCASCADE — опционально, флагом `VKD_WITH_OCCT`.

## Границы

Вероятность разгерметизации не рассчитывается: валидированного уравнения
пробоя для многослойной ткани скафандра в открытых источниках нет.
Выдаётся карта экранирования и ожидаемое число попаданий.
