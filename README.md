# ВКД-Риск

Оценка радиационного и ударного риска при выходе космонавта в открытый космос.

КосмоХакатон, кейс «Орбитальный риск», 18–20 сентября 2026.

## Что делает

Целевой веб-сервис получает орбиту и космическую погоду, оценивает факторы
в окне ВКД и сравнивает два варианта одинаковой длительности. Выдаёт
обоснованное предпочтение, компромисс, равнозначность или недостаток данных.
Есть текущий режим и история мая–июня 2024 с отдельным прогнозом из прошлого.

Две линии плана: космопогода на траектории и статистика природных
метеороидов по ECSS. SOCRATES — дополнительное предупреждение о сближении
станции. Уточнение охвата согласуется по `docs/PLAN_REVIEW.md`.

## Главный результат

Рекомендация прослеживается до исходных данных, времени публикации и
правила расчёта; видны покрытие и ограничения. Зонная модель скафандра
остаётся возможным дополнением после обязательного сервиса.

**Состояние `efaa86d`:** собраны исследования/данные, договор, типы и каркас
пакетов. Полноценный сервис ещё не реализован; типы v2 не заморожены.
Фактическая готовность и доказательства — [docs/PROGRESS.md](docs/PROGRESS.md).

## Два удалённых адреса

Работаем на GitHub, сдаём на GitVerse. Репозиторий один, адресов два.

| имя | адрес | роль |
|---|---|---|
| `origin` | GitHub | рабочий: ежедневные коммиты, журналы, обмен между нами |
| `gitverse` | `git@gitverse.ru:hackrus.experts/kosmo-piter_matmehovtsy_111.git` | сдача: там должно лежать готовое решение к дедлайну |

Обычная работа — короткие ветки `codex/*` / `claude/*`, проверка второй
стороной, затем интегратор Б объединяет в main. Передача каждые 60–90 минут
и на контрольных рубежах: [протокол](docs/TEAM_SYNC.md).
Коммиты и публикация выполняются в пределах текущего поручения пользователя.

Отправка проверенного main на сдачу — ответственность интегратора; доступ
и адрес назначения проверяются заранее. Команда после приёмки версии:

```
git push gitverse main
```

Доступ к GitVerse выдают модераторы вручную после привязки username
в личном кабинете хакатона. Подключение по SSH, ключ добавляется
в профиле GitVerse: Настройки, вкладка «Ключи SSH/GPG».

## Запуск

Веб-сервис на Python. С 18.09 проект перестроен под официальную постановку
кейса: настольное приложение, C++, Qt и CMake отменены.

Целевые команды после создания приложения и фиксации окружения:

```
python -m pip install -e ".[dev]"
streamlit run app/main.py
```

В исходной версии `efaa86d` файла `app/main.py` ещё нет; это не инструкция
запуска уже работающего сервиса. Точную установку из lock добавляет Б на I0.
Разработка А идёт нативно на macOS; Windows и Parallels не нужны.

Целевая версия Python и полный lock зависимостей фиксируются в первый день
(CONTRACT.md, правило 6).

## Границы

Вероятность разгерметизации не рассчитывается: валидированного уравнения
пробоя для многослойной ткани скафандра в открытых источниках нет.
Статистический результат — ожидаемое число попаданий в опорную пластину,
с явно указанными моделью и охватом; он не задаёт риск для космонавта.
Модель техногенного мелкого мусора не реализована, сезонный компонент
метеороидов ещё требует проверки. Допуск к реальной ВКД сервис не выдаёт.
