# CONTRACT — замороженные договорённости

Этот файл читают оба ассистента перед любой работой.

**Менять его может только человек и только по устной договорённости вдвоём.**
Ни Claude, ни Codex не правят этот файл по своей инициативе. Если нужно
изменение — ассистент пишет об этом в свой журнал в поле «Нужно от товарища»
и останавливается.

---

## 1. Единицы

Единица входит в имя переменной. Всегда.

| величина | единица | суффикс имени |
|---|---|---|
| поверхностная плотность защиты | г/см² | `_g_cm2` |
| длина | м | `_m` |
| толщина | мм | `_mm` |
| время | с | `_s` |
| энергия частицы | МэВ | `_MeV` |
| поглощённая доза | мГр | `_mGy` |
| эквивалентная доза | мЗв | `_mSv` |
| поток | част./(см²·с) | `_per_cm2_s` |
| флюенс | част./см² | `_per_cm2` |
| площадь | м² | `_m2` |
| угол | радианы | `_rad` |
| высота орбиты | км | `_km` |

`double d = ...` — нарушение. `double d_g_cm2 = ...` — норма.

## 2. Зона — базовая структура

Семь зон, имена фиксированы латиницей:

```
helmet_visor_up      шлем, светофильтры подняты
helmet_visor_down    шлем, светофильтры опущены
torso                торс, жёсткая часть
arms                 рукава
legs                 ноги
gloves               перчатки
boots                ботинки
```

Поля зоны:

| поле | тип | единица | кто заполняет |
|---|---|---|---|
| `id` | строка | — | заморожено выше |
| `title_ru` | строка | — | Claude |
| `areal_density_g_cm2` | double | г/см² | Claude, из `data/zones.csv` |
| `al_equivalent_g_cm2` | double | г/см² | Claude, = areal × (Z/A)/0,4818 |
| `area_m2` | double | м² | Codex, из геометрии |
| `primitive_id` | строка | — | Claude |

**Числа поверхностной плотности заморожены:**

| зона | г/см² | Al-эквивалент |
|---|---|---|
| helmet_visor_up | 0,665 | 0,722 |
| helmet_visor_down | 1,227 | 1,335 |
| torso | 0,599 | 0,641 |
| arms | 0,161 | 0,180 |
| legs | 0,161 | 0,180 |
| gloves | 0,20 | 0,22 |
| boots | 0,20 | 0,22 |

Источник каждого числа — `docs/zony_skafandra.md`.

в журнал, в поле «Нужно от товарища».

## 4. Стык между половинами

Ровно два места.

**Место первое — зона.** Определена выше. Claude даёт поверхностную плотность,
Codex даёт площадь.

**Место второе — среда во времени.** Codex выдаёт массив:

```
время_utc, высота_km, широта_deg, долгота_deg, B_модуль_nT, в_аномалии_bool
```

Claude из него берёт условия для дозы, Codex сам берёт для удара.

## 5. Плагинный ABI

```c
int  vkd_plugin_abi_version();
void vkd_register_modules(vkd::ModuleRegistry&);
void vkd_destroy_module(vkd::IModule*);
```

Резолв по имени, без метаданных Qt. Кто создал в DLL — тот и удаляет.
Хост принимает диапазон версий и отклоняет несовпадение с записью в журнал.

**Версия ABI поднимается только с отметкой в этом файле.**

Текущая: **v1**.

## 6. Правила кода

1. **Никаких молчаливых клампов.** Значение вне области — отказ с сообщением.
2. Единицы в имени переменной.
3. Ни одного `setStyleSheet` в коде, всё в `resources/style.qss`.
4. Каждая физическая константа с источником в комментарии: документ, пункт, таблица.
5. Заголовки в `include/vkd/` заморожены, меняются по согласованию.
6. Кто создал в DLL, тот и удаляет.
7. Никаких глобальных переменных через границу DLL.
8. Тесты на инварианты, не на значения.

## 7. Два обязательных теста

| тест | что проверяет |
|---|---|
| поворот модели в изотропном поле не меняет интеграл | угловые веса, трассировка |
| секторная сумма равномерной полусферы = табличное значение ОСТ | ядро свёртки |

---

## 8. Метод свёртки

ОСТ 134-1044-2007, приложение И.

- ядро — таблица **плоскости** (нормальное падение), не полусферы;
- сумма по секторам с весом телесного угла;
- при малых толщинах учитывать обратное рассеяние: барьер 2R, доза на глубине R;
- таблица **полусферы** используется только для проверки.

---

## 9. Чего не заявляем

- вероятность разгерметизации — нет валидированного уравнения пробоя ткани;
- доза на кожу не сравнивается с пределом 500 мЗв/год — у кожи свой предел;
- поверхностная плотность «Орлана» сверх металла — не опубликована.
