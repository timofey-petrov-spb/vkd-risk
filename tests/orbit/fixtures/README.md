# Численные эталоны A3

`SGP4-VER.TLE`, `tcppver.out` — опубликованные проверочные данные Vallado
и соавторов [AIAA 2006-6753](https://celestrak.org/publications/AIAA/2006-6753/),
взятые без преобразования байтов из пакета sgp4 2.27. Размеры и SHA-256 —
в `sgp4_manifest.json`; `.gitattributes` запрещает изменение концов строк.
Тест использует спутники 5 и 4632: ближний и глубокий режим SGP4.

`igrf13_reference.json` — независимый гармонический синтез
[pyIGRF 0.3.3](https://github.com/zzyztyy/pyIGRF/tree/v0.3.3), шесть точек.
`build_igrf_reference.py` воспроизводит JSON при установленном pyIGRF.
Для сопоставимости коэффициенты и календарная интерполяция задаются
одинаковые с `data/orbit/IGRF13.shc`; вычисление поля выполняет pyIGRF,
а не ppigrf. Обе стороны используют одну физическую модель: это проверка
численной реализации, а не независимая валидация модели наблюдениями.

При исходном сравнении встроенные наборы коэффициентов различались,
и модуль поля расходился до 2,375 нТ. В JSON сохранены и те значения.
После согласования входов допуск оставлен прежним, 1 нТ; он учитывает
различия численных геодезических преобразований. Физическая погрешность
IGRF этим числом не ограничивается.

Обычные тесты читают готовый JSON, поэтому pyIGRF не нужен приложению
или CI. Регенерировать фикстуру при каждом запуске тестов не следует.
# Векторы EME2000/J2000

`inertial_reference.json` получен `build_inertial_reference.py` с ERFA
(pyerfa 2.0.1.5). Генератор не импортирует Skyfield или код приложения:
ERFA gmst82/gst06a/pnm06a/bp00 преобразует нативные r/v SGP4 в EME2000.
Шесть моментов покрывают 32 часа. DUT1 зафиксирован из используемых
приложением таблиц, поэтому проверяется независимая реализация **матрицы**,
а не независимые параметры вращения Земли или абсолютная точность эфемерид.
Обе линии используют мгновенный поворот скорости без малого frame-rate
члена; его точность не проверяется этим совпадением.

Допуски 1 см и 0,01 мм/с обнаруживают ошибки системы, знака и единиц,
с запасом на различия рядов IAU. Нативный SGP4 отдельно проверяется
опубликованными векторами Vallado. Перегенерация — явный запуск
`python tests/orbit/fixtures/build_inertial_reference.py` с дополнительным
pyerfa; обычные тесты читают JSON без этой зависимости.
