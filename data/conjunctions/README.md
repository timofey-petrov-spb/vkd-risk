# Собственный расчёт сближений: сохранённые исходники

`demo_2026-09-19/` содержит неизменённые тела ответов CelesTrak GP CSV,
сжатые gzip. SHA-256 в manifest относится к **распакованным исходным байтам**;
отдельно сохранён хеш gzip. Время доступности — наше получение, не эпоха орбиты.
Для active записана консервативная верхняя граница доступности после собственного
успешного скачивания; это указано в доказательстве. Остальные времена сняты при
получении. Современные данные не пригодны для строгой отсечки в 2024 году.

Выборка: active + имена DEB + имена R/B. Не полный каталог; ограничение принципиально.
Исходники публичны, источник — [CelesTrak](https://celestrak.org/),
условия — [usage policy](https://celestrak.org/usage-policy.php).
Для оперативного использования обновлять через A4 с кешем, не выдавать пример за live.

`screening_24h.json` — все найденные минимумы ≤50 км и полный аудит исключений.
`numerical_validation.json` — сравнение сеток/фильтров и независимого локального
минимума расстояния, включая SHA-256 проверенных файлов реализации.
Подробности и команды — `docs/integration/CONJUNCTIONS_2026-09-19.md`.
