# Исходные уведомления DONKI за май–июнь 2024

Это часть A1: инвентаризация исходных сообщений, а не готовый строгий replay.
Запросы захватывают также 30 апреля как контекст на начало периода. Границы
API запрошены с перекрытием; повторные объекты удалены из реестра по
идентификатору сообщения и хешу содержимого, исходные ответы сохранены полностью.

- `records.json` — отдельная запись на версию содержимого каждого сообщения.
- `responses.json` и `*_receipt.json` — URL запросов, время фактического
  получения, HTTP-метаданные и SHA-256 полных ответов.
- `raw/*_response.json` — точные байты ответа сервера.
- `raw/messages/` — каноническое JSON-извлечение каждого объекта: UTF-8,
  ключи отсортированы, компактные разделители, завершающий LF. Это не
  отдельный HTTP-ответ: `response_refs` указывает на оригинальные байты.
- `coverage.json` — число сообщений по дням/типам и шести отсечкам;
  это не полное покрытие физической обстановки.
- `errors.json` — ошибки получения или обязательных полей, если были.

`published_utc` берётся как более поздняя из API `messageIssueTime` и
`Message Issue Date` внутри тела. API может обрезать секунды: сообщение,
опубликованное в 20:21:53, нельзя считать доступным в 20:21:00.
Оба исходных времени сохранены. `available_utc` здесь означает доступность
по заявленному времени выпуска; независимого архивного доказательства
неизменности тела к этому моменту нет. Статус строгой пригодности поэтому
`dated_notification_pending_content_and_version_audit`, а не безусловный допуск.

SHA-256 фиксирует содержимое полученной сейчас версии. Он не доказывает,
что это содержимое было доступно в 2024 году. API не выдаёт отдельный
`versionId` уведомления; `provider_version = null`, версия снимка — хеш.
Не угадываем версию по последнему числу в `messageURL`.

Время события, прогнозный интервал и область (Земля/МКС либо другие объекты)
ещё предстоит извлечь в A2. Сейчас `valid_from/to = null`, `channels = []`,
`target_scope = unclassified_pending_A2_content_audit`. Уведомления для
других планет/аппаратов нельзя автоматически считать земными. Отсутствие
сообщений в день не означает отсутствия воздействия.

DONKI — исследовательский продукт NASA, что указано в исходных сообщениях;
он не заменяет эксплуатационные предупреждения NOAA. Для основной
датированной линии в этом наборе используются выпуски NOAA из `../noaa/`.

Источник API: https://kauai.ccmc.gsfc.nasa.gov/DONKI/WS/get/notifications

Есть и расхождение, не объясняемое округлением: `20240516-7D-001`
имеет время API `2024-05-16T03:44:00Z`, а в теле —
`2024-05-16T17:40:05Z` (разница 13 ч 56 мин 5 с). Реестр выбирает
позднее время, а `coverage.json` перечисляет конфликты от одной минуты.
Это недельный ретроспективный обзор 8–14 мая, его нельзя автоматически
превратить в прогноз. Тип сообщения требует содержательной проверки A2.
