## 1. `kp_ap_sn_f107.txt` — главный файл, 5,5 МБ

**Что:** Kp, ap, Ap, число пятен и F10.7 в одном файле, посуточно **с 1932 года
по 16.09.2026**. 34 633 строки.

**Источник:** GFZ Helmholtz Centre Potsdam, `kp.gfz.de`. Лицензия CC BY 4.0,
кроме чисел пятен — CC BY-NC 4.0.

**Формат:** фиксированная ширина, колонки по порядку:

```
YYYY MM DD  days  days_m  Bsr  dB  Kp1..Kp8  ap1..ap8  Ap  SN  F10.7obs  F10.7adj  D
```

`Kp1..Kp8` — Kp за восемь трёхчасовых интервалов суток UT, `ap1..ap8` — то же
в линейной шкале ap. `Ap` — суточное среднее. `SN` — число пятен.
`F10.7obs` — наблюдённый поток, `F10.7adj` — приведённый к 1 а.е.
`D` — признак окончательности: 0 предварительные, 1 Kp окончательный,
2 и Kp, и SN окончательные.

**Зачем нам:** `F10.7` и `Ap` — прямые входы модели атмосферы
ГОСТ Р 25645.166-2004. `Kp` — признак геомагнитной возмущённости, влияет на
границу проникновения частиц. **В дозу Kp не переводится**, см.
`docs/ZAMYSEL.md` раздел 6.

**Как используется в сервисе (с 19.09.2026):** поставщик истории
`experiments/stub_history.py` (`gfz_archive_kp_samples`) читает из этого файла
окончательный ряд Kp за 1 мая — 30 июня 2024 (488 трёхчасовых интервалов,
`D = 2` → качество `final`) для **разбора после факта** и как факт «буря в
окне» в экспериментах Т5 (`experiments/forecast_lines.py`,
`scripts/make_examples.py`). Времени публикации по интервалам у ряда нет,
поэтому в строгом «прогнозе из прошлого» все эти интервалы исключаются
отсечкой с причиной (CONTRACT §10: Kp GFZ окончательный — только проверка
после факта). Каждая сырая запись несёт строку файла, SHA-256 файла, признак
`D` и дату снимка. Сверка с DONKI: строка `2024 05 10`, интервал 15–18 UT,
Kp6 = 7,667 = `allKpIndex` карточки `2024-05-10T15:00:00-GST-001` с
`observedTime` 18:00Z (observedTime DONKI — конец интервала).

**Состояние на 16.09.2026:** F10.7 = 99,7 · Ap = 8 · SN = 28. Активность
умеренно низкая.

## 2. `iss.tle` — орбита станции

**Источник:** CelesTrak, NORAD 25544.

**Разобрано:**

| параметр | значение |
|---|---|
| наклонение | 51,6307° |
| оборотов в сутки | 15,491523 |
| период | 93,0 мин |
| большая полуось | 6797,3 км |
| **высота средняя** | **419,2 км** |
| эксцентриситет | 0,0004826 |

**Важно для расчёта.** Высота 419 км лежит между столбцами **400** и **600 км**
таблиц ОСТ — интерполируем. Наклонение 51,6° есть в таблице **К.3.5 напрямую**,
без интерполяции. Для поясов интерполируем между 30° и 60° (К.1.5/К.1.6
и К.2.5/К.2.6).

**Обновление:** TLE стареет за неделю. Перед защитой скачать заново:

```
curl -L "https://celestrak.org/NORAD/elements/gp.php?CATNR=25544&FORMAT=TLE" -o iss.tle
```

**Внимание (19.09.2026):** этот файл — справочная копия без записи о
получении (время файла на свежем клоне равно времени клонирования, а не
скачивания). Слой источников `experiments/stub_sources.py` при отказе всех
адресов TLE и отсутствии кеша берёт **не его**, а `data/orbit/iss.tle` вместе
с записью `data/orbit/manifest.json` (адрес, `fetched_utc`, SHA-256,
свидетельство получения — модуль A3), сверяя байты с манифестом; в статусе
источника пишется «снимок репозитория data/orbit/iss.tle, получен … с
celestrak.org (манифест A3)». Живой запрос идёт по цепочке адресов из
`config/settings.toml` параллельно, в расчёт берётся первый по порядку
настроек разобранный ответ; тело ответа сохраняется как есть
(`data/cache/tle_raw_<хост>.txt` + SHA-256), нормализованные три строки —
производная запись со ссылкой на исходную.

## 3. `igrf14coeffs.txt` — модель магнитного поля

**Что:** коэффициенты сферических гармоник IGRF-14, степень до 13,
эпохи с 1900 по 2030, в нТл. Для степеней до 8 даны скорости векового хода.

**Источник:** IAGA через NOAA NCEI.

**Зачем нам:** модуль поля вдоль трассы, а через него **геометрия
Южно-Атлантической аномалии**. Аномалия определяется физически, как область
пониженного поля, а не нарисованным контуром.

Связано с приложением Д ОСТ 134-1044-2007 (геоцентрические и L-B координаты).

**Помнить:** аномалия дрейфует на запад со скоростью **0,3° в год**, около 10°
с момента создания моделей поясов. ECSS-E-ST-10-04C называет это прямо
и в скобках указывает применение — выход космонавта.

## 4. `goes_protons_3day.json` — протонный поток, трое суток

**Что:** интегральный поток протонов GOES-18 по порогам энергии, 6880 записей.
Поля: `time_tag`, `satellite`, `flux`, `energy`.

**Источник:** NOAA SWPC.

**ОСТОРОЖНО.** GOES меряет на **геостационарной орбите**, вне магнитосферной
защиты. Переносить его напрямую на космонавта на низкой орбите **нельзя**:
на наклонении 51,6° геомагнитное обрезание отсекает большую часть протонов
вспышки, кроме приполярных участков.

Правильное применение: GOES показывает, **что событие идёт**. Поток у
космонавта считается через функцию проникновения, приложение Ж ОСТ 1044.

**Обновление:**

```
curl -L "https://services.swpc.noaa.gov/json/goes/primary/integral-protons-3-day.json" -o goes_protons_3day.json
```

**Как используется в сервисе:** только как последний резерв при отказе
источника и отсутствии кеша (`experiments/stub_sources.py`). Время получения
снимка известно лишь датой (17.09.2026, время суток не записано), поэтому в
статусе пишется «снимок репозитория …, скачан 17.09.2026 (README; время суток
не записано), давность не меньше …», а давность самих наблюдений считается по
`time_tag` записи. Значение из снимка к моменту защиты устарело и по правилу
свежести GOES (`goes_max_age_min`) даёт лишь частичное покрытие — это
объявляется, а не скрывается.

## 7. Кеш живых источников `data/cache/` (не в репозитории)

Пишется слоем `experiments/stub_sources.py`. Каждой записи `<ключ>` соответствует
`<ключ>.meta.json`: `fetched_utc` (время получения), `url` (адрес), `sha256` и
`bytes` данных; для TLE — ещё `raw_response_path`, `raw_response_sha256`,
`provider_time`. Сначала пишется meta, затем данные, каждый файл — через
временное имя и `os.replace`. При чтении SHA-256 сверяется: несовпадение или
отсутствие meta означает «время получения неизвестно» — статус так и звучит,
давность не подменяется нулём. Ответ Kp GFZ для ещё идущего трёхчасового
интервала помечается «интервал … не завершён — предварительная оценка GFZ».
