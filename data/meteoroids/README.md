# Контрольные данные A5

Спецификация: `docs/methods/METEOROIDS_GRUN_SPEC.md`.

- `grun_reference.json`: 30 табличных точек J-5 и формула; поправки J-6;
  контроль N за 6/8 ч; отдельные величины сезонного потока до согласования геометрии.
- `ecss_c2_streams.json`: все 49 фактически напечатанных строк C-2, с SHA
  исходного PDF. Текст стандарта говорит о 50 потоках; пропущенная строка
  не восстановлена предположением.
- Основной Grün использует граммы, сезонная модель McBride — килограммы.
- Файлы не разрешают объявить сезонную модель реализованной или заменить
  отсутствие данных нулём. Область геометрии явно описана в спецификации.

Это данные и ТЗ для реализации Б, не дублирующий модуль `vkd/assess/`.
