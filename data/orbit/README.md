# Снимки входов орбитального модуля

`manifest.json` хранит SHA-256, размер, исходный источник и версию каждой
записи. Модуль проверяет байты перед расчётом; изменение данных требует
новой согласованной записи манифеста.

- `IGRF13.shc`, `IGRF14.shc` — коэффициенты из ppigrf 2.1.0
  ([первичный репозиторий](https://github.com/IAGA-VMOD/ppigrf)).
  IGRF-13 используется для 2024, чтобы не подменять историческую модель
  более поздней ревизией. SHA фиксирует конкретный набор коэффициентов.
- `iss.tle` — прямой ответ CelesTrak для NORAD 25544, полученный
  18.09.2026 UTC. Время получения не является эпохой элементов; эпоху
  считывает SGP4. Снимок не обновляется автоматически и непригоден вне
  заданного предела возраста относительно обеих границ запроса.
- Исторические OEM хранятся отдельно в `data/source_registry_2024/`.
- `validation_environment.json` фиксирует фактические версии проверки А;
  не заменяет общий lock, которым управляет Б.

Геометрия, единицы, ограничения и вызов: `vkd/orbit/README.md`.
