# Окончательный Kp для разбора мая–июня 2024

13 291 байт, 61 день, 488 ячеек. Источник: GFZ, [описание данных](https://kp.gfz.de/en/data),
[набор Kp](https://doi.org/10.5880/Kp.0001), Kp — CC BY 4.0.
Сохранённые, но не используемые столбцы солнечных пятен имеют CC BY-NC 4.0;
исходные атрибуция и лицензии сохранены в заголовке.

Это неизменённые заголовок и строки мая–июня из git-объекта
`e846a441e0c152b9787fde55cdc5ff5362395bc6:data/spaceweather/kp_ap_sn_f107.txt`.
Отбор строк байтовый, без преобразования CRLF. Хеш полного родителя,
правило извлечения и точный хеш среза записаны в records.json.
Время первоначальной загрузки известно только датой из README коллеги;
`fetched_utc` здесь явно означает время локального импорта, НЕ публикацию GFZ.
Время исторической доступности не доказано: **только разбор**, никакого
автоматического продвижения окончательного ряда в прогноз из прошлого.

Kp1…Kp8 — восемь интервалов по 3 ч от 00:00 UTC, значение timestamp у
EnvironmentSample — конец интервала. D=0: предварительный Kp; D=1/2:
окончательный. -1.000: пропуск, не ноль. В вычисления не идут ap/Ap/SN/F10.7.
Источник определения колонок и D — оригинальный заголовок провайдера.

`validation/gfz_api_20240510_12.json` — отдельно полученный официальный
JSON: 24 ячейки 10–12 мая, timestamp обозначает НАЧАЛО интервала.
receipt.json фиксирует адрес, получение и SHA. Тест сравнивает времена и
значения с ASCII. Оба формата имеют общее происхождение GFZ, поэтому это
проверка парсинга и единиц, а не независимое измерение геомагнитной бури.

Проверки: `python -m pytest tests/sources/test_gfz_archive.py tests/history/test_bundle.py -q`.
Границы 32 ч + задержка, пропуски, порча, ложная публикация, качество,
дубли/перекрытия выпусков, изоляция снимков и полное разрешение raw/хеша.
